EDITABLE EXCEL REPORT TEMPLATES

These .xlsx files are the editable design templates used by the Hospital Management System Excel exports.

1. Open the template you want in Microsoft Excel.
2. Change colors, fonts, logo area, headings, column widths, borders, and other formatting.
3. Keep the report/header row structure in place so the export can reuse the styling.
4. Save the file with the same filename in this folder.
5. Download Excel from the corresponding module to use the template style.

Templates:
- doctors.xlsx
- patients.xlsx
- pharmacy.xlsx
- laboratory.xlsx
